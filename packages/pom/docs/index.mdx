# pom: Presentations as Code

**pom** is a common model and toolkit for creating presentations as code. It is not only a PPTX generation API: agent skills, Markdown, JSX/TSX, and visual editors all converge on **pom XML**, which can be previewed, validated, and rendered by the same core pipeline.

[Get started with an AI agent and pom CLI →](/getting-started#ai-agent--pom-cli)

[Use the TypeScript library directly →](/getting-started#typescript-library)

## How the pom kit fits together

pom XML is the editable source of truth and intermediate representation (IR) shared by every authoring surface. Tools do not introduce separate presentation models; they operate on or produce the same pom model.

```text
Authoring
pom XML / pom-md / pom-jsx / pom-slide / visual editor
                         │
                         ▼
Core model
              pom XML → PositionedNode
                         │
                         ▼
Rendering / Tools
PPTX / SVG / PNG · pom-cli / pom-vscode / Playground
```

- **Authoring surfaces** let people and agents express the same presentation in the form best suited to the task.
- **Core model** parses and lays out pom XML as positioned presentation nodes.
- **Rendering and tools** preview, inspect, or export that shared model as editable PPTX or rendered SVG/PNG.
