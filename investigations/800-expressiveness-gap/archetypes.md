# アーキタイプ定義

本調査で対象とする 6 アーキタイプと、共通お題を 1 つ決めて各アーキタイプにあてはめる際のサブテーマを記す。

## 共通お題（コンテキスト）

**「FY2026 Q3 SaaS プロダクトレビュー」**

社内向け四半期レビューデッキを想定。AI コーディング支援 SaaS「Cosmo」の Q3 実績と Q4 計画を、経営チームに 10 分で伝える、というシナリオで全 6 アーキタイプを生成する。

「KPI ダッシュボード」「2 案比較」「タイムライン」など pom が表現を担保する代表的な構成を、ひとつのデッキ内で **同じ視覚言語で並べたときに整合するか** という観点も併せて見たい。

## 6 アーキタイプ

`pom-slide` skill の「スライドアーキタイプ」表をベースに、画像比較で観察したい論点が明確なものを選んだ。

| アーキタイプ         | サブテーマ                                                  | 観察したい論点                                                               |
| -------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 表紙                 | 「FY2026 Q3 プロダクトレビュー — Cosmo」                    | グラデーション背景 / 大きな display 文字 / 装飾の自由度 / Layer 配置         |
| アジェンダ           | 5 セクションの目次                                          | ナンバリングの装飾 / セクション間の階層表現 / アクセントカラーの使い方       |
| KPI ダッシュボード   | MRR / アクティブユーザー / NRR / Churn の 4 タイル + 変化率 | カードレイアウト / 数字の display サイズ / 推移インジケーター / sparkline 風 |
| 2 案比較             | 「自社開発」 vs 「OSS 採用」                                | 左右対称カード / ヘッダ色分け / 推奨マーク / セル単位の装飾                  |
| タイムライン         | Q4 の 4 マイルストーン                                      | `Timeline` ノードの見た目 / 日付の強調 / フェーズごとの色分け                |
| 引用・キーメッセージ | 顧客の声引用 + キーメッセージ                               | 大きい引用符 / 引用テキストのサイズ / 出典の控えめ表示 / 1 メッセージの強調  |

タイトル表記の都合上「セクション扉」「データ（Chart）」「まとめ / CTA」など、他にも有効なアーキタイプはあるが、本調査では既存ノード機能と表現自由度の観察が分かりやすい上記 6 種に絞った。

## デザイントークン（共通）

全アーキタイプを同じ視覚言語で揃える。`pom-slide` skill の「ダーク・テック」プリセットをベースに微調整。

| ロール  | 値                                                       |
| ------- | -------------------------------------------------------- |
| base    | `#0B1220` (深紺ダーク)                                   |
| surface | `#111B2E`                                                |
| ink     | `#F1F5F9`                                                |
| muted   | `#94A3B8`                                                |
| accent  | `#38BDF8` (シアン)                                       |
| accent2 | `#A78BFA` (バイオレット) — gradient と KPI 推移用 2 色目 |

- グラデーション: `linear-gradient(135deg, #38BDF8 0%, #A78BFA 100%)` を表紙とアクセント部分の差別化に使う
- 主フォント: 本文 / 数字とも `Inter`（HTML 版）/ pom 側はデフォルトの `Noto Sans JP` を踏襲（pom は Inter をバンドルしていないため）
- 余白: 8 の倍数 (`8 / 16 / 24 / 32 / 48 / 64`)
- スライドサイズ: 1280 × 720 px
